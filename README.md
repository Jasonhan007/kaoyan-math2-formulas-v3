# 考研数学二公式大全（v3）

覆盖**高等数学**与**线性代数**的公式速查网页，共 **116 条**公式（含历年真题高频公式），严格按数学二考试范围整理（不含无穷级数等超纲内容）。

- **多页面结构**：首页为章节目录，每个小节独立一页（`section.html?id=xx`），另有收藏页——单页不冗长
- 每条公式包含：**名称 · KaTeX 表达式 · 成立条件 · 易错提醒**
- 功能：页内搜索（带高亮）、章节胶囊导航、桌面侧栏目录、收藏（本地持久化，含来源链接）
- 简洁浅色界面（iOS 风格玻璃卡片），适配手机、平板、电脑（iPhone 18 Pro 402×874 已实测）
- 公式数据在 `data.js`，与样式完全分离，方便扩充
- KaTeX 已本地化到 `vendor/`，**无需联网即可渲染公式**
- 已配置 Web App manifest 与 apple-touch-icon，Safari 可「添加到主屏幕」全屏使用

## 本地运行

```bash
python -m http.server 8765 --bind 127.0.0.1
# 打开 http://127.0.0.1:8765/
```

## 页面

| 文件 | 说明 |
|---|---|
| `index.html` | 首页：章节目录 |
| `section.html?id=ga1` | 章节详情页（12 个小节通用模板） |
| `favorites.html` | 我的收藏 |
| `data.js` | 公式数据（String.raw LaTeX） |
| `app.js` / `styles.css` | 交互逻辑 / 样式 |
| `vendor/` | KaTeX 0.16.9 本地文件与字体 |
